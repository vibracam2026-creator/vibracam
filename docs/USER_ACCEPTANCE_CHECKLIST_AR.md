# قائمة تحقق اختبار المستخدم قبل النشر

## الحساب والهوية

| المجال | ما يجب اختباره |
|---|---|
| التسجيل | إنشاء حساب، التحقق من العمر، الحقول الإلزامية، رسائل الأخطاء |
| تسجيل الدخول | بريد/كلمة مرور، رمز 2FA الاختياري، إعادة التوجيه عند وجود جلسة |
| البيانات الأساسية | الاسم، اسم المستخدم، البريد، الهاتف، الميلاد، العمل، التعليم، الإقامة |
| التوثيق | حالة التوثيق، طلب/إدارة التوثيق، الرسائل الآمنة |
| الأمان | تغيير كلمة المرور، تفعيل 2FA، الأجهزة والجلسات، تسجيل الخروج |

## الخلاصة والمحتوى

| المجال | ما يجب اختباره |
|---|---|
| النشر | منشور نصي عادي، نجاح/فشل، تحديث الخلاصة، حذف اختبار النشر |
| الوسائط | رفع صورة/فيديو، حدود الحجم والنوع، رسالة الخطأ عند الفشل |
| التفاعلات | الإعجاب، التعليق، المشاركة، الحفظ، العدادات، الإشعار |
| stories/reels/live | فتح النماذج، الرفع، الحالات الفارغة، عدم كسر المسارات |
| moderation | السماح برسالة/منشور عادي، منع الإباحي، منع الترويجي، منع الروابط المشبوهة إن كانت القاعدة تغطيها |

## الرسائل والتواصل

| المجال | ما يجب اختباره |
|---|---|
| الرسائل الفردية | فتح محادثة، إرسال رسالة، المعاينة، القراءة، مؤشر الكتابة، الصوت |
| الوسائط في الرسائل | مرفق صورة/فيديو/ملف، الرفع، المعاينة، الحذف أو الفشل |
| المجموعات | إنشاء مجموعة، إضافة عضو، إرسال رسالة، إدارة الأعضاء، مغادرة المجموعة |
| القنوات | إنشاء قناة، فتحها من inbox، نشر تحديث، الاشتراك/إلغاء الاشتراك |
| الإشعارات | إشعار رسالة/تفاعل، فتح الإشعار، تعليم كمقروء، كتم الصوت |

## الخصوصية والإبلاغ

| المجال | ما يجب اختباره |
|---|---|
| الجمهور والرؤية | من يرى الملف والمنشورات والمتابعين وطرق العثور على المستخدم |
| الحظر | حظر حساب اختبار، منع الرسائل، فك الحظر |
| الإبلاغ | الإبلاغ عن حساب/منشور/رسالة، سبب البلاغ، منع البلاغات الكيدية أو التكرارية |
| السلامة | الابتزاز، التحرش، خطاب الكراهية، الانتحال، التصيد، المحتوى الإباحي، الترويج الاحتيالي |
| معلومات المستخدم | تنزيل البيانات، الأذونات، التطبيقات/المواقع، سجل النشاط |

## تجربة المستخدم والنشر

| المجال | ما يجب اختباره |
|---|---|
| اللغة | العربية والإنجليزية، RTL/LTR، عدم عودة النصوص إلى العربية عند الإنجليزية |
| الحركة والصوت | انتقالات ناعمة، زر كتم واضح، احترام `prefers-reduced-motion` |
| الاستجابة | عرض الهاتف والسطح المكتبي، عدم خروج المحتوى عن الشاشة، أزرار قابلة للمس |
| الأداء | التحميل الأول، حالات الانتظار، الأخطاء، حجم JavaScript، عدم وجود أخطاء console |
| النشر | إعداد البيئة، HTTPS، الأسرار، قاعدة بيانات الإنتاج، OAuth، البريد، التخزين، النسخ الاحتياطي |
