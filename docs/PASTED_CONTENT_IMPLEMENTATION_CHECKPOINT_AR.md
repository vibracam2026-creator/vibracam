# نقطة تحقق تنفيذ متطلبات pasted_content.docx

**التاريخ:** 16 أغسطس 2026

اختُبرت نسخة الإنتاج المحلية بعد البناء على `http://127.0.0.1:3001/account-center` باستخدام حساب الاختبار المحلي.

| الميزة | نتيجة الفحص |
|---|---|
| حالة البريد في البيانات الأساسية | ظهرت حالة «البريد بانتظار التأكيد؛ يمكنك طلب رابط جديد من أمان الحساب». |
| 2FA | أُوقف الإعداد التجريبي ثم فُعّل من جديد، وظهر QR بصيغة data URL مولّد محليًا مع السر النصي. |
| تفضيلات الدردشة والإشعارات | ظهرت إشعارات البريد والهاتف، معاينة الرسالة، الاهتزاز، إشعارات تغيّر رموز الأمان، الصوت، أعداد التفاعلات، الوضع المظلم، والترجمة. |
| تفضيلات الدردشة التفصيلية | ظهرت خيارات حجم الخط، خلفية المحادثة، نغمة الرسائل الفردية، نغمة المجموعات، والتنزيل التلقائي. |
| مفاتيح المرور | ظهر دعم WebAuthn الفعلي للمتصفح مع توضيح أن التسجيل الكامل يحتاج تخزين WebAuthn آمنًا على الخادم؛ زر التسجيل بقي معطلًا بدل ادعاء تنفيذ غير مكتمل. |

لا يحتوي هذا السجل على سر 2FA أو قيمة QR الخام.

أظهر قسم الجمهور والرؤية إعدادات طلبات التواصل والعثور بالبريد والهاتف والجمهور الافتراضي والتعليقات والمتابعين، ثم أظهر إعدادات آخر ظهور ومتصل الآن ومن يستطيع الإضافة للمجموعات ومؤشرات القراءة والموقع المباشر. وأظهر قسم الأذونات حالة الكاميرا والميكروفون وجهات الاتصال ومعرض الصور، مع تقدير التخزين المحلي والتنزيل التلقائي للوسائط، دون حذف بيانات الخادم.

اختُبر زر الإبلاغ من ملف مستخدم آخر؛ فُتح حوار عربي يحوي 17 سببًا منظمًا وحقل تفاصيل، ثم أُرسل بلاغ تقني تجريبي بنجاح وظهرت رسالة «تم إرسال البلاغ للمراجعة». لم يُغلق الحساب تلقائيًا.

رُبطت تفضيلات حجم الخط وخلفية الدردشة والصوت الاختياري بالمحادثات المباشرة والجماعية. كما أُضيف تنظيف للبيانات المحلية الخاصة بالمتصفح فقط مع رسالة تأكيد وتحذير صريح بعدم حذف بيانات الخادم.
