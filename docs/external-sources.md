# مصادر معيارية للكتالوجات

استخدم التدقيق مصادر معيارية عامة لتحديد نطاق الكتالوجات، مع اعتبار البيانات الموجودة في المشروع هي مصدر التنفيذ المحلي:

1. ISO 639 — صفحة المنظمة الدولية للغات ورموزها: https://www.iso.org/iso-639-language-code
2. Library of Congress — جدول ISO 639-2 الذي يتضمن رموز ISO 639-1 والأسماء الإنجليزية: https://www.loc.gov/standards/iso639-2/php/code_list.php
3. ISO 3166 — صفحة المنظمة الدولية لرموز الدول والتقسيمات: https://www.iso.org/iso-3166-country-codes.html
4. Unicode CLDR — مستودع البيانات المحلية للدول والتقسيمات واللغات: https://cldr.unicode.org/index/charts
5. Provinces of Algeria — قائمة الولايات الجزائرية الحالية ومجموعة الولايات الإحدى عشرة المضافة: https://en.wikipedia.org/wiki/Provinces_of_Algeria

ملاحظة: قائمة المناطق في المشروع تحتوي بعد التنظيف على 244 دولة/إقليم و2,413 تقسيمًا و7,786 مدينة. قائمة اللغات الموسعة في `client/src/lib/regions.ts` أصبحت 196 إدخالًا، بما يتجاوز مجموعة ISO 639-1 الشائعة (نحو 184 رمزًا) وتضم بعض اللغات/اللهجات العملية ذات الرموز الثلاثية الموجودة سابقًا في المشروع.

بحسب مصدر ولايات الجزائر، أصبحت الجزائر مقسمة إلى 69 ولاية، وتشمل الولايات الإحدى عشرة المضافة: Aflou، El Abiodh Sidi Cheikh، El Aricha، El Kantara، Barika، Bou Saâda، Bir El Ater، Ksar El Boukhari، Ksar Chellala، Aïn Oussera، وMessaad.

15. Algeria-Cities — مستودع بيانات البلديات الجزائرية: https://github.com/ihahachi/Algeria-Cities

تم استخدام الملف `json/algeria_cities.json` من المستودع، وهو يضم 69 ولاية و1,541 بلدية مع الأسماء العربية والفرنسية ورموز الولايات والبلديات. دُمجت البلديات داخل `WORLD_REGIONS` بصيغة `الاسم الفرنسي — الاسم العربي`. تحقق التدقيق البرمجي من 69 ولاية و1,541 بلدية، وأصبح إجمالي المدن/البلديات في القاموس 9,267.

> ملاحظة: تختلف بعض المصادر بحسب السنة في عرض التقسيم الإداري الجزائري؛ لذلك حُفظ ملف المصدر داخل المشروع ووُثّق مصدر الدمج صراحة.
