# منظومة الأمان والاعتدال في VibraCam

تستخدم المنصة طبقات متتابعة قبل النشر وبعد البلاغ. تُفحص النصوص أولًا بمرشح محلي سريع للمحتوى الجنسي الصريح، ثم تُرسل إلى نموذج ذكاء اصطناعي بإخراج JSON منظم. عند اكتشاف محتوى جنسي صريح أو ضار بدرجة الحجب، يُرفض النشر قبل إنشاء السجل النهائي. وعند تعذر خدمة الاعتدال، يعمل المسار الآمن المغلق ويمنع النشر مؤقتًا بدل السماح بمحتوى غير مفحوص.

تُفحص الصور قبل تخزينها في مساحة الملفات عبر نموذج بصري، مع تسجيل النتيجة في `contentModerationChecks`. أما الفيديوهات فتظل بحاجة إلى عامل استخراج إطارات/فحص فيديو مخصص في بيئة الإنتاج؛ لذلك لا ينبغي اعتبار فحص الصور وحده شهادة سلامة للفيديوهات. يمكن تشغيل هذا العامل لاحقًا باستخدام FFmpeg أو خدمة اعتدال فيديو متخصصة مع إبقاء سياسة الحجب قبل النشر.

تُعالج البلاغات الفورية عبر `judgeReport`. لا يُحذف المحتوى تلقائيًا إلا عندما يكون الحكم مؤيدًا والإجراء `delete`، بينما البلاغات غير المؤيدة لا تغيّر المحتوى الآمن. وتُسجل قرارات الذكاء الاصطناعي والثقة والإجراء في سجل الاعتدال والبلاغ.

يسمح التسجيل بعمر منصة أدنى قدره 13 عامًا، لكن الحسابات دون 18 عامًا تُنشأ في حالة `parental_pending` وتُوجّه إلى مسار موافقة ولي الأمر. ويُمنع الحساب غير المعتمد من المكالمات العشوائية والبث والمساحات الصوتية، بينما لا يُفعل الحساب إلا بعد موافقة الولي. يجب مواءمة هذه السياسة مع قوانين الدولة وشروط الخدمة قبل الإطلاق التجاري.

أُضيفت أيضًا حماية للمساحات الصوتية: التحقق من حالة الحساب قبل الدخول، أحداث Socket.IO للإشارات، وبث WebRTC شبكي للمتحدثين مع استقبال صوتي للمستمعين. لا يستطيع ترقية أو إزالة متحدث إلا مضيف المساحة.

## اختبارات المراجعة

| الاختبار | النتيجة المتوقعة |
|---|---|
| نص يحتوي لفظًا إباحيًا صريحًا | حجب فوري قبل استدعاء النموذج |
| تعذر خدمة نموذج الاعتدال | حجب مؤقت وإتاحة إعادة المحاولة |
| صورة صريحة | رفض الرفع قبل التخزين وتسجيل القرار |
| بلاغ كيدي على محتوى آمن | لا حذف تلقائي |
| حساب قاصر بلا موافقة | منع المكالمات والبث والمساحات |
| مضيف يرقّي متحدثًا | تحديث المشاركين عبر Socket.IO |
| مستمع يستقبل بث متحدث | إنشاء اتصال WebRTC واستقبال الصوت |
