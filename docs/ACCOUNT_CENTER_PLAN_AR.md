# تصميم مركز الحسابات في VibraCam

## الهدف

يوحّد مركز الحسابات إدارة البيانات الأساسية والأمان والتوثيق والتفضيلات والجمهور والأذونات والمعلومات في مساحة عربية واحدة تحت المسار `/account-center`.

## الأقسام

| القسم | الوظائف الأساسية |
|---|---|
| البيانات الأساسية | الاسم، اسم المستخدم، البريد الإلكتروني، رقم الهاتف، تاريخ الميلاد، الدولة والمدينة، العمل والتعليم وأماكن الإقامة، وتنزيل نسخة البيانات |
| كلمة السر والأمان | تغيير كلمة المرور، المصادقة الثنائية، الأجهزة والجلسات، إنهاء الجلسات الأخرى |
| التوثيق | حالة البريد، طلب توثيق الحساب، حالة مراجعة الهوية، وإدارة الإعلانات السياسية كإعداد توضيحي قابل للتوسعة |
| التفضيلات | إشعارات الهاتف والبريد، إظهار أعداد التفاعلات، الوضع الداكن، اللغة والمنطقة، وترجمة المنشورات |
| الجمهور والرؤية | قابلية العثور على الحساب، الجمهور الافتراضي للمنشورات والقصص، التعليقات العامة، المتابعون، وإدارة المحظورين |
| الأذونات والمعلومات | التطبيقات ومواقع الويب المرتبطة، سجل النشاط، وتنزيل المعلومات |

## ملاحظات التنفيذ

سيُعاد استخدام جداول `users` و`localCredentials` و`authSessions` و`privacySettings` الحالية. وستُضاف جداول إعدادات الحساب والتفضيلات والتوثيق والأذونات وسجل النشاط والمصادقة الثنائية عند الحاجة، مع تخزين الأسرار الحساسة على الخادم فقط وعدم عرضها في الاستجابات العامة.
